## 🛠️ Tech Stack (Rencana Pengembangan)
- **Frontend:** Tailwind CSS (CDN & Config Eksternal), JavaScript Modern (Modular)
- **Backend:** PHP Native (Multi-Page Modular Architecture)
- **Database:** MySQL (via Laragon)
- **Version Control:** Git & GitHub

## 🚀 Quick Start untuk Tim

### 1. Clone Repositori
```bash
git clone https://github.com/ridoq/Nafaistore.git
cd Nafaistore
```

### 2. Pindah ke Branch `develop`
```bash
git checkout develop
git pull origin develop
```

### 3. Panduan Kontribusi
Sebelum membuat fitur baru atau mengubah kode, **wajib** membaca panduan kerja tim di [CONTRIBUTING.md](CONTRIBUTING.md).

> [!IMPORTANT]
> **Aturan Emas:** Jangan pernah melakukan `git push` langsung ke branch `main` atau `develop`. Selalu buat branch fitur sendiri dan ajukan via **Pull Request (PR)**.
